# 네이버 뉴스 검색 프로그램

네이버 뉴스 검색 API를 활용해 사용자가 입력한 키워드의 뉴스 기사를 검색하고, 결과를 카드 형태로 보여주는 FastAPI 웹 프로그램입니다.

검색 결과에는 기사 제목, 요약, 발행일, 기사 링크, 원문 링크, 대표 이미지가 표시됩니다. 대표 이미지는 기사 원문 페이지의 메타 태그와 이미지 태그를 분석해 가져옵니다.

사용자는 관심 있는 기사를 즐겨찾기에 추가할 수 있으며, 저장된 기사는 `/favorites` 페이지에서 다시 확인할 수 있습니다. 즐겨찾기 데이터는 MongoDB에 저장됩니다.

이 프로그램은 뉴스 검색 결과를 단순 목록이 아니라 이미지가 포함된 카드 UI로 보여주어, 기사 내용을 더 쉽게 탐색하고 필요한 기사를 따로 모아볼 수 있도록 구성되어 있습니다.
